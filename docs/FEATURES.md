# 功能介绍（公开说明）

本文与应用内「系统设置 → 授权与版本」功能清单对齐，供采购、部署与对外介绍使用。  
**基础版**与**专业版**安装包均在本仓库 Releases 提供；源码不公开。**专业版增值**需 `ad-manager-pro-*` 包 + 有效授权。

安装包与在线更新均来自公开仓库 Releases：  
https://github.com/Aidan-996/ad-manager-releases/releases

---

## 一、基础版已包含（无需授权）

| 能力 | 说明 |
|---|---|
| 目录运维 | 用户 / 组 / 计算机 / OU 增删改查、导入导出、重置密码、启停解锁 |
| 策略浏览与编辑 | 组策略浏览、域密码策略 / FGPP、OU 委派（本地超管） |
| 安全巡检与评分 | 安全中心风险检查、安全评分 |
| 仪表盘待处理 | 锁定 / 密码即将过期 / 已过期账号卡片（LDAP） |
| 预置报表（手工） | 导出 CSV / 查看报表；**定时邮件**需授权 |
| 操作审计 | 全量操作审计日志 |
| 平台账号与 AD 登录 | 本地账号三角色、AD 组映射、TOTP 双因素、自助改密 |
| API 令牌 | 本地超管创建长效 Bearer，脚本调用 REST 无需交互登录与 CSRF |
| 单可写域 | 最多 1 个可写域；超出域保留为只读 |
| 单域用户上限 | 标准档硬上限 2000；升级专业 / 企业后提高 |

---

## 二、授权后解锁（Professional+，基础版二进制即可）

导入有效 `.lic` 后菜单与接口可用；未授权时菜单隐藏、接口 404。

| 能力 | 说明 |
|---|---|
| 多域管理 | 按授权数量（或不限）管理多个可写 AD 域 |
| 数据大屏 | 多域汇总的实时数据大屏 |
| 定时报表 | 预置报表按计划发送邮件 |
| LAPS / BitLocker | 查看计算机本地管理员密码与 BitLocker 恢复密钥（全程审计） |
| AD 回收站 | 查看已删除对象并还原 |
| 告警中心 | 规则引擎、渠道通知与事件处置 |

---

## 三、专业版可开启（需专业版安装包 + 授权）

下列能力在基础版安装包中仅作展示；实际运行需下载 **`ad-manager-pro-*`** 包并导入授权。

| 能力 | 说明 |
|---|---|
| MAC 账号 | 批量创建 MAB / 802.1X 终端账号，预检、分批执行、FGPP 风险提示 |
| 锁定分析 | 跨 DC 汇总锁定信息、WinRM 事件定位来源、批量解锁与锁定趋势 |
| 特权账号监控 | 递归展开内置特权组成员，风险标签，成员变更实时告警 |
| AD 健康检查 | 域控可达性、时间偏差、FSMO、证书、复制元数据等，导出 PDF |
| 入职 / 离职自动化 | 入职模板与 HR Excel；离职禁用、退组、迁移 OU、延迟清理 |
| 账号生命周期策略 | 陈旧用户/计算机：通知 → 禁用 → 删除 |
| 审批工作流 | 加组、重置密码、延长过期等需审批，全程审计 |
| 变更审计与回滚 | 属性 / 组成员历史、差异对比、一键还原 |
| 合规报告 | 定时邮件发送合规报告包（PDF / Excel） |
| GPO 增强管理 | OU 链接树、GPO 对比、元数据备份与还原预览 |
| 选择性导出 | 按 OU / 状态 / 部门 / 闲置天数筛选并导出 Excel |
| 林间信任（企业版） | 只读查看 trustedDomain；跨林管理所需 |
