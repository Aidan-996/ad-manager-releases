# 架构说明（公开摘要）

完整技术架构（分层、钩子、授权闸门）维护在**私有**基础版源码仓 `ad-manager` 的 `docs/architecture.md`。本页仅说明对外可见的交付模型。

## 三仓模型

| 仓库 | 可见性 | 角色 |
|---|---|---|
| `Aidan-996/ad-manager` | 私有 | 基础版源码 |
| `Aidan-996/ad-manager-pro` | 私有 | 专业版叠加源码与签发工具 |
| **本仓** `Aidan-996/ad-manager-releases` | 公开 | 教程 + 安装包；**无源码** |

## 主交付（v23.2+）

- **Windows / macOS 本地版**：双击运行，本机 HTTPS `https://127.0.0.1:9443/`；推荐 `*-setup.exe` / `.dmg`。
- 应用内「检查更新」默认查询**本仓** Releases；典型用户无需 GitHub Token。
- Linux + nginx 服务器部署仍可用，非当前默认工作流；**默认不部署到 VPS**。

## 能力分层（简）

1. **标准（未授权）**：目录运维、策略浏览、安全巡检、手工报表、审计、平台账号等；1 可写域 / 单域 ≤2000 用户。
2. **授权解锁（基础版二进制 + `.lic`）**：多域、大屏、定时报表、LAPS/BitLocker、回收站、告警中心等。
3. **专业版增值（`ad-manager-pro-*` + 授权）**：入职离职、生命周期、审批、变更审计、合规、GPO 增强、选择性导出等；企业档另含林间信任。

详见 [FEATURES.md](./FEATURES.md)。当前对外版本：**v23.2.6**。
